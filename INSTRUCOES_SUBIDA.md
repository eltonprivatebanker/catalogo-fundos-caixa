# Catálogo de Fundos CAIXA — v261

Arquivos atualizados:
- index.html
- style.css
- app.js

## O que mudou

Esta versão cria uma camada visual nova para o módulo **Cenário monetário**, preservando IDs e lógica existente.

Principais ajustes:
- visual mais premium para Selic, CDI, Copom e CDI mensal;
- hierarquia mais clara: Selic como card principal;
- menos bordas concorrendo entre si;
- tipografia mais consistente e menos "gritada";
- calendário do Copom mais compacto;
- no mobile, o módulo fica mais baixo e menos poluído;
- CDI mensal no mobile mostra apenas os dois meses principais;
- botão do calendário mais discreto;
- título do CDI mensal mais curto.

## Como subir

Substitua no GitHub os arquivos:
- index.html
- style.css
- app.js

Depois faça Ctrl + F5 no desktop e reabra a página no celular.
